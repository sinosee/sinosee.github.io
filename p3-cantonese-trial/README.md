# 廣東話小幫手（試版）

這是給小三學生使用的瀏覽器試用頁面，幫助未諳廣東話的同學聆聽課文，並用普通話提問、聽廣東話回答。請用 Safari（iPad）或 Chrome／Edge（電腦）開啟 `index.html`。無需安裝應用程式。

## 老師如何設定課文

1. 在主頁按右下方較小的「老師設定課文」。
2. 輸入四位數字密碼。預設密碼是 **8800**（設定頁內也會再次顯示，以免忘記）。
3. 從學校已授權的電子書複製課文：標題可選填，全文必須貼上。
4. 按「儲存課文」。課文會儲存到課堂資料庫，學生在學校、家中或其他裝置打開同一個網址都可以聆聽。請先發佈包含 `p3CantoneseTrial` 的資料庫規則，並在 Firebase 控制台設定 `p3CantoneseTrial/teacherPin`（與頁面密碼相同，預設 8800）。
5. 建議先按「試聽聲音」，確認這部裝置可以讀出廣東話。
6. 如需更換課文，貼上新內容後再儲存即可。按「清除課文」會同時刪除雲端課文，所有裝置都不再顯示。

請只貼上你有權使用的課文，不要把課文檔案傳給無關的人。

## 學生如何「聽課文」

- 主頁按「聽課文」。畫面會顯示課文，並用廣東話朗讀。
- 「播放」開始聆聽，「暫停」後再按「播放」會由當前句子繼續，「重播」由開頭再讀。
- 正在讀的句子會反黃標示。
- 若尚未設定課文，畫面會請學生先找老師設定。

## 學生如何「對答」

- 主頁按「對答」。請用**普通話**提問日常生活（家庭、學校、食物、喜好、天氣、朋友、週末等）。
- 按「開始對話」後才會收音；請允許使用麥克風。說完後，小幫手會用廣東話出聲回答。
- 若不能使用麥克風，可在輸入框輸入，或按話題按鈕。此時程式會先用普通話讀出問題，再用廣東話回答。兩邊都會出聲，不會只有文字。
- 對話紀錄會顯示在畫面中，標示「你」與「小幫手」。

## iPad 使用提示

- 建議用 **Safari** 開啟。第一次播放或錄音時，請點一下畫面並允許聲音／麥克風。
- 朗讀功能在已有廣東話語音的 iPad 上效果最好（常見語音名稱包括 Sinji、Meijia 等）。若裝置沒有廣東話語音，畫面會顯示提示，並嘗試以香港中文朗讀。
- 如在「本機檔案」直接開啟本頁，麥克風有時不能用；用學校網站以 https 提供，或由老師在可靠的本機網頁伺服器開啟，會較穩定。即使沒有麥克風，仍可用輸入框或話題按鈕練習，並且聽到聲音。
- 請把裝置音量打開，不要開啟靜音鍵。若沒有聲音，先按「聽課文」的「播放」，或到老師設定頁按「試聽聲音」。

## 課文與私隱

課文由老師貼上後，儲存在課堂用的 Firebase Realtime Database（路徑 `p3CantoneseTrial/lesson`），不會寫進公開網頁原始檔。學生只需打開同一個網址，不必輸入密碼。請只貼上你有權用於本班教學的課文。

清除瀏覽器網站資料不會刪除雲端課文；要刪除請在老師頁按「清除課文」。本機亦會暫存一份，以便短暫離線時仍可朗讀。

本試版的對答是預設的日常話題回應，並非即時人工智能，離線時仍可對答。聆聽雲端課文需要網絡連線。
