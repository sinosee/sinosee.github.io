# 廣東話小幫手（試版）

這是給小三學生使用的瀏覽器試用頁面。學生可以拍攝課文，讓程式辨認文字並用廣東話朗讀；也可以用普通話提問，聽廣東話回答。請用 Safari（iPad）或 Chrome／Edge（電腦）開啟本頁。無需安裝應用程式。

## 學生如何「拍攝讀字」

1. 主頁按「拍攝讀字」。
2. 按「拍攝課文」用相機拍照，或按「從相簿選擇」選取已有照片。
3. 程式會在這部裝置辨認中文，然後顯示文字。如有個別錯字，可直接在畫面改正，再按「儲存改正」或「播放」。按「播放」開始聆聽廣東話朗讀，「暫停」後再按「播放」會由當前句子繼續，「重播」由開頭再讀。正在讀的句子會反黃標示。
4. 如要更換照片，按「再拍攝」。如課文有多頁，可按「加入另一頁」。
5. 第一次辨認需要網絡，以便下載中文辨識資料。之後同一部裝置會較快。

請靠近課文的文字部分拍攝，光線充足，文字盡量填滿畫面，並避免只拍插圖或反光。辨認後如仍有錯字，可在播放前改正。照片只在這部裝置處理，不會上載到網絡。

## 學生如何「對答」

- 主頁按「對答」。請用**普通話**提問日常生活（家庭、學校、食物、喜好、天氣、朋友、週末等）。
- 按「開始對話」後才會收音；請允許使用麥克風。說完後，小幫手會用廣東話出聲回答。
- 若不能使用麥克風，可在輸入框輸入，或按話題按鈕。此時程式會先用普通話讀出問題，再用廣東話回答。兩邊都會出聲，不會只有文字。

## iPad 使用提示

- 建議用 **Safari** 開啟。第一次拍攝、播放或錄音時，請允許相機、聲音和麥克風。
- 朗讀功能在已有廣東話語音的 iPad 上效果最好（常見語音名稱包括 Sinji、Meijia 等）。若裝置沒有廣東話語音，畫面會顯示提示，並嘗試以香港中文朗讀。
- 請把裝置音量打開，不要開啟靜音鍵。

## 私隱

辨認到的文字會暫存在這部裝置，方便稍後繼續聆聽。清除瀏覽器網站資料，或在頁面按「清除文字」，就會刪除。本試版的對答是預設的日常話題回應，並非即時人工智能，離線時仍可對答。拍攝讀字在第一次使用時需要網絡。
